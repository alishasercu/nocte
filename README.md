# NOCTE · landingspagina

Landingspagina voor het fictieve parfummerk NOCTE (eindopdracht Creative Automation, Arteveldehogeschool, Alisha Sercu).

- `index.html`: hero, verhaal, geuren en CTA met het MailerLite-formulier
- `assets/css/style.css`: merkkleuren met paletschaal, Fraunces en DM Sans
- `assets/img/`: beelden voor de pagina (Figma Weave en eigen productfoto's)
- `assets/figma/`: beelden voor de bulkvarianten in Figma (gebruikt via `beeld_url` in de CSV)

Gebouwd met Claude Code. Live via GitHub Pages.
